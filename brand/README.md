# Transilience logo set

The mark is an atom's orbit split in two, with the amber half slipped up and across: a jump from one state to the next.
Version: "Split orbit, tapered" (concept 17). A refinement pass is planned.

## Files

| File | Use |
|---|---|
| `transilience-lockup.svg` | Main logo (mark + wordmark) on light backgrounds |
| `transilience-lockup-dark.svg` | Main logo on dark backgrounds |
| `transilience-lockup-mono-navy.svg` / `-mono-white.svg` | One-colour versions, for print or busy photos |
| `transilience-mark.svg` | Mark alone, light backgrounds |
| `transilience-mark-dark.svg` | Mark alone, dark backgrounds |
| `transilience-mark-mono-navy.svg` / `-mono-white.svg` | One-colour mark |
| `transilience-mark-small.svg` | Heavier mark for sizes of 32 px and under |
| `favicon.svg`, `favicon.ico` | Browser-tab icon (the SVG switches colours in dark mode) |
| `png/` | PNG copies: marks at 512 and 1024 px, lockups 2400 px wide, `avatar-light-800.png` and `avatar-dark-800.png` for LinkedIn and Substack, `apple-touch-icon.png` for phones |

## Colours

| | Light backgrounds | Dark backgrounds |
|---|---|---|
| Main | Navy `#13233B` | Off-white `#E7EBE3` |
| Accent | Deep amber `#B87500` | Yellow `#F2B705` |
| Background | Paper `#ECEFEA` | Night `#0F1724` |

## Type

Wordmark: "transilience" in lowercase Manrope Medium (500). In the SVG files the letters are already drawn as shapes, so no font is needed to open them.

## Rules of thumb

- Leave clear space around the logo at least as wide as the mark's electron and gap combined.
- Keep the amber half amber; use the mono files when only one colour is possible.
- Do not stretch, rotate or recolour the halves separately.
